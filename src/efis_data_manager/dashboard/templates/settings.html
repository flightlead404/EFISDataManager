Settings

These settings control how this Analysis dashboard interprets and displays your flight data. Some settings live elsewhere: your tail number, archive & USB-image folders, chart-product selection, and Seattle Avionics login are in the Data Manager (the menu-bar app) under Settings…. Changes here take effect after you click Save Settings.

Engine Configuration

Water-cooled/Rotax support (coolant temperature surfacing, 2-cylinder handling, high-RPM scaling) is not yet implemented. If you fly a water-cooled engine and would like to help test this, please get in touch — volunteer testers are welcome.

Aux Channel Mapping ?Your GRT EIS has six auxiliary inputs (Aux1–Aux6). Which sensor is wired to each channel varies by install, so tell the dashboard what each channel represents. Only channels you map here appear in the flight view, extreme buttons, and episode detection. The EIS applies each sensor's scale/offset internally, so these values are already in engineering units — no conversion happens here.

Assign each aux channel to the parameter wired to it. Choose None for unused channels. Choose Custom to enter your own display label and unit. Unmapped channels are hidden everywhere in the dashboard.

Flight Detection

Analysis Thresholds ?Limits used to flag Alerts and color-code readings. A "caution" is an early warning; a "redline" is a hard limit. Set these to your engine's published limits and your personal margins — they don't change the data, only when it's flagged.
