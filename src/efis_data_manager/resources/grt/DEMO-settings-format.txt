The data field for source data type 7 (Settings) contains key-value pairs as
ASCII strings in the format "key=value".  There is one pair in each packet.
The value can be almost any string, excluding newline sequences.  It must be
interpreted with each setting.

This example recorded the Serial Port 1 Baud Rate at 19200.
The setting-identifier (SID) for Serial Port 1 Baud Rate is 1.

07 - The packet source is 7 for Settings.
00 00 00 00 - packet timestamp
00 00 00 07 - The length of the packet data field is 7.
31 3d 31 39 32 30 30 - The ASCII string "1=19200".
